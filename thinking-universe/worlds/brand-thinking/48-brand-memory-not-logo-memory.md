# Brand Memory ≠ Logo Memory

## Hook

**মানুষ আপনার Logo মনে রাখলেই কি আপনার Brand মনে রাখল?**

## The Idea

Mark visual memory-তে বসে; meaning episodic memory-তে বসে। প্রথমটা দেখলে চেনে, দ্বিতীয়টা না দেখলেও বলে।

## Deep Article

### Problem

Business-এর ভেতরে এই ভুলটা সবচেয়ে দামি, কারণ এটা অদৃশ্য। সবাই একমত যে `Logo recall-ই brand recall।` — তাই কেউ সেটা পরীক্ষা করে না।

আমার পর্যবেক্ষণ সহজ: Mark visual memory-তে বসে; meaning episodic memory-তে বসে। প্রথমটা দেখলে চেনে, দ্বিতীয়টা না দেখলেও বলে।

যেখানেই একটা অংশকে পুরোটা বলে ভুল করা হয়, সেখানেই decision ভুল জায়গায় যায়। এই concept-টার কাজ শুধু `Brand Memory ≠ Logo Memory` বলা না—`Logo recall-ই brand recall।` এই default-টাকে প্রশ্ন করা।

### Common belief

বেশিরভাগ মানুষ এই ধাপটা এড়িয়ে যায় কারণ ধারণাটা এই: *Logo recall-ই brand recall।* এটা সম্পূর্ণ ভুল না—এটা অসম্পূর্ণ। অসম্পূর্ণ ধারণাই বেশি ক্ষতি করে, কারণ এতে থেমে যাওয়া যায়।

### Author's observation

আমি বিষয়টা এই দিক থেকে দেখি: Mark visual memory-তে বসে; meaning episodic memory-তে বসে। প্রথমটা দেখলে চেনে, দ্বিতীয়টা না দেখলেও বলে।

### Argument

Logo Memory = recognition. Brand Memory = meaning + feeling + evidence. তিনটার সমষ্টি না হলে memory quote করার মতো হয় না।

এখানে আমি দুটো জিনিস আলাদা করছি: একটা **অংশ**, আর একটা **পুরো ব্যবস্থা**। অংশটা সুন্দর হলেই ব্যবস্থাটা দাঁড়ায় না; ব্যবস্থা না থাকলে অংশটা শুধু একটা খরচ হয়ে থাকে।

### Breakdown

পুরো argument-টা ৪-৫ ধাপে ধরলে `CUE → STORY → SENSATION → SAYING` দাঁড়ায়—

1. Cue: mark, colour, sound—trigger।
2. Story: আপনার সাথে কী ঘটেছে—এক বাক্যে।
3. Sensation: কেমন লেগেছে—গরম, নিরাপদ, হালকা।
4. Saying: অন্যকে কী বলে—এটাই memory-এর বাহ্যিক প্রমাণ।

প্রতিটা ধাপ আগেরটার উপর দাঁড়ায়। ধাপ বাদ দিলে chain ভাঙে, আর chain ভাঙলে ফলাফল হয় random।

### In plain words

সোজা ভাষায় বললে: Brand Memory ≠ Logo Memory মানে এই নয় যে ছোট অংশটা বাদ দিন। মানে হলো—cue: mark, colour, sound—trigger। দিয়ে থেমে গেলে শেষটা পাওয়া যায় না। Saying: অন্যকে কী বলে—এটাই memory-এর বাহ্যিক প্রমাণ।

যিনি বিষয়টা নিয়ে কাজ করেন না, তিনি প্রথমটা দেখে সিদ্ধান্ত নেন। যিনি কাজ করেন, তিনি শেষটা দেখে সিদ্ধান্ত নেন। পুরো তফাৎটাই এখানে।

### Example

দুই brand-এর Logo একই রকম recall (৭০%)। প্রথমটা নিয়ে মানুষ বলে "ওদের নাম M"। দ্বিতীয়টা নিয়ে বলে "ওদের একবার ভুল order হয়েছিল, ১০ মিনিটে বদলে দিয়েছে"। Memory-এর গুণমান আলাদা।

### Counter-example

প্রতিটা positioning-এর একটা limit থাকে, না হলে সেটা doctrine হয়ে যায়। এখানে আমার limit: Recall-ই যথেষ্ট, যদি purchase interval খুব ছোট হয় (daily essentials)-সেখানে story তৈরির দরকার কম, cue দ্রুত কাজ করে।

এই ধরনের ক্ষেত্রে `Brand Memory ≠ Logo Memory` কে rigid rule না ধরে একটা default lens হিসেবে ব্যবহার করা ভালো।

### Where it gets misread

এই ধরনের লেখার সবচেয়ে বড় বিপদ হলো এটাকে অজুহাত হিসেবে ব্যবহার করা। কেউ কেউ বলবে, "তা হলে Logo-র দরকারই নাই" বা "design নিয়ে ভাবার কী আছে"। সেটা এই argument-এর উল্টো ব্যবহার।

আমার বক্তব্য সোজা: Logo recall-ই brand recall। এই default-টা ভুল, কিন্তু সমাধান হলো উপেক্ষা না—সঠিক ক্রম। `CUE → STORY → SENSATION → SAYING` এই chain-এ প্রথম ধাপটা বাদ দিলে বাকি ধাপ কাজ করে না।

যে কেউ এই concept-কে নিজের অলসতার লাইসেন্স বানাতে চায়, সে আসলে ঠিক সেই ভুলটাই করছে—একটা অংশকে পুরোটা ভাবা। এবার উল্টো দিক থেকে: অংশটাকে ছোট না করে ব্যবস্থার ভেতরে তার আসল মাপটা বসানোই কাজ।

### Implication

**Business:** Brand asset test করুন এইভাবে: "আপনার সম্পর্কে মানুষ কোন গল্পটি বলে?" না এলে memory শুধু visual, decision-এর জন্য নেই।

**Marketing:** Signature element (sound, shape, ritual) memory-তে mark-এর চেয়ে বেশি থেকে যায়—কারণ সেটা অনুভব করা যায়।

**Brand:** Brand-এর প্রকৃত share হলো মানুষের স্মৃতির গভীরতা, impression-এর সংখ্যা নয়।

### What this changes in a meeting

মিটিং-এ এই concept আনার একটাই উদ্দেশ্য—সিদ্ধান্তটা এক ধাপ এগিয়ে নেওয়া। কথা এড়ানোর জন্য না। তাই তিনটা প্রশ্ন সামনে রাখুন:

1. আমরা কোনটাকে পুরোটা ভাবছি—আসলে কোনটা শুধু একটা অংশ?

2. এই সিদ্ধান্তের ফল গ্রাহক কোন ধাপে দেখতে পাবে?

3. আগামী ৯০ দিনে এই ব্যবস্থার কোন ধাপটা আমরা সত্যিই করব?

ধাপগুলো কাঁচা রাখুন—

- Cue: mark, colour, sound—trigger।
- Story: আপনার সাথে কী ঘটেছে—এক বাক্যে।
- Sensation: কেমন লেগেছে—গরম, নিরাপদ, হালকা।
- Saying: অন্যকে কী বলে—এটাই memory-এর বাহ্যিক প্রমাণ।

যে ধাপটায় কেউ দায়িত্ব নিতে চায় না, সেটাই আপনার `Brand Memory ≠ Logo Memory` সংক্রান্ত আসল অভাব।

### Test you can run today

এই concept কাজে লাগবে কিনা বোঝার সহজ উপায় হলো নিজের কাজটার উপর প্রশ্নটা চালানো: **আপনার brand নিয়ে মানুষ সবচেয়ে বারবার কোন বাক্যটা বলে?**

প্রতিটা ধাপের পাশে এক লাইনে উত্তর লিখে ফেলুন। যেখানে ফাঁকা, সেখানেই কাজ। এই concept-এর পুরো দাম সেই ফাঁকা জায়গাটুকুতে।

### Conclusion

Logo মনে থাকে; গল্প মুখে থাকে।

Perception বদলালে behaviour বদলায়; behaviour বদলালে reputation বদলায়। এই series-এর প্রতিটা লেখায় আমি একটা জিনিসই করছি: কাউকে ছোট করা না, জিনিসগুলোর ক্রম ঠিক করা। `Brand Memory ≠ Logo Memory`-ও তাই।

Logo Memory = recognition. Brand Memory = meaning + feeling + evidence. তিনটার সমষ্টি না হলে memory quote করার মতো হয় না।

আমি পুরো জিনিসটা এভাবে ধরি:

**CUE → STORY → SENSATION → SAYING**

→ Cue: mark, colour, sound—trigger।
→ Story: আপনার সাথে কী ঘটেছে—এক বাক্যে।
→ Sensation: কেমন লেগেছে—গরম, নিরাপদ, হালকা।
→ Saying: অন্যকে কী বলে—এটাই memory-এর বাহ্যিক প্রমাণ।

দুই brand-এর Logo একই রকম recall (৭০%)। প্রথমটা নিয়ে মানুষ বলে "ওদের নাম M"। দ্বিতীয়টা নিয়ে বলে "ওদের একবার ভুল order হয়েছিল, ১০ মিনিটে বদলে দিয়েছে"। Memory-এর গুণমান আলাদা।

সোজা কথায়—
**Logo মনে থাকে; গল্প মুখে থাকে।**

আপনার brand নিয়ে মানুষ সবচেয়ে বারবার কোন বাক্যটা বলে?
