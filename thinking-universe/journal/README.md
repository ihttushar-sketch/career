# Journal — দিনপ্রতি একটা ফাইল

প্রতিদিন আপনি যা দিচ্ছেন, সেটা ইনবক্সে ছড়িয়ে পড়ে। জার্নাল সেটাকে **দিন ধরে** আলাদা রাখে, যাতে
পরে উল্টোদিকে দেখা যায়: “এই conceptটা আসলে আমার কোন বাক্য থেকে শুরু হয়েছিল।”

```text
2026-10-07.yaml   ← source: আপনার বাক্য (verbatim), আজকের নির্দেশনা, কী তৈরি হলো
2026-10-07.md     ← generated: npm run day — সংখ্যা গিট + inbox + gate থেকে আসে
```

## নিয়ম

1. **`.yaml`-ই আসল।** এতে শুধু আপনার বাক্য, আর যেখানে সেটা পড়েছে সেই পথ।
2. **`.md` কখনো হাতে লেখেন না।** `npm run day` regenerate করে — তাই gap সংখ্যা কখনো পুরনো থাকে না।
3. **এজেন্ট-দেওয়া নমুনা আলাদা সেকশনে থাকে** (`agent_supplied_demos`)। ওগুলো গঠন দেখানোর জন্য,
   আপনার position না — না মিললে মুছে দিন।
4. কোনো নতুন belief জার্নালে ঢোকে না: কোনো ফাঁকা ঘর থাকলে `NEEDS_AUTHOR_INPUT` লেখা থাকে।

```yaml
date: 2026-10-08

  - text: "…"
    became: "…"
    status: done | note | blocked
perceptions:   # আজ আপনার দেওয়া চিন্তা — lane, node, thought, drafted path, gaps_open

```
